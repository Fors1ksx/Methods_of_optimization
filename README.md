# Методы оптимизации — анимированный учебник по ЛР1 и ЛР2 (вариант 21)

Учебник вместо видео на YouTube на движке **[Papermorph](https://github.com/DozenTwelve/Papermorph)** `engine-v2.12` (копия движка — в `site/opt/lib`, проверена: в сеть не обращается; сам скилл Papermorph из проекта удалён из-за предупреждений аудита безопасности): озвученные уроки, где графики, итерации методов и код из листингов оживают под рассказ, а проверки и практика идут прямо в уроке.

**Всё содержание — строго по отчётам ЛР1 и ЛР2:** те же методы (равномерный поиск, золотое сечение, Брент; касательные, Брент), формулировки, обозначения, код из листингов, таблицы и выводы. Методы, которых нет в отчётах, есть только в Лаборатории — для сравнения.

## Как запустить

```
python -m http.server 8766 -d site
```
и открыть <http://127.0.0.1:8766/opt/>. Звук работает только через HTTP-сервер.

## Главы

| ЛР1 | ЛР2 |
| --- | --- |
| 1 Постановка и точный ответ | 6 Постановка и точный ответ |
| 2 Метод равномерного поиска | 7 Метод касательных |
| 3 Метод золотого сечения | 8 Метод Брента |
| 4 Метод Брента | 9 Результаты, сравнение, выводы |
| 5 Результаты, сравнение, выводы | |

Управление уроком: `Пробел` — пуск/пауза, **удерживать `Пробел` или правую кнопку мыши — 2×**, `<` `>` — скорость 0,75–2× (кнопка скорости открывает меню), **полосу шагов можно зажать и тянуть** — над курсором номер шага, название и время, урок играет с места, где отпустили; `←` `→` — шаги, `C` — субтитры, `G` — конспект главы поверх урока, `?` — все клавиши.

## Практика и справка

| Раздел | Что это |
| --- | --- |
| **Экзамен** | Случайные вопросы всех глав, таймер, разбор, ссылка на шаг урока с объяснением; числовые ответы проверяются с допуском |
| **Работа над ошибками** | Вопросы, на которые последний ответ был неверным |
| **Тренажёр** | Бесконечные задачи со случайными числами по методам отчётов: аналитика, сетка, точки и шаги золотого сечения, вершина параболы и шаг Брента, касательные, секущая, подсчёт вычислений |
| **Лаборатория** | Методы отчётов (и для сравнения — другие методы из заданий) на любой функции, по шагам, с таблицей итераций, сравнением и таблицей по ε; для варианта 21 числа совпадают с программами |
| **Конспекты** | Каждая глава — текст отчёта с формулами, таблицами и кодом; печатается в PDF |
| **К защите** | Вопросы по содержанию отчётов с ответами из отчётов, разделы отчёта |

## Для разработки

```sh
python tools/tts.py content/opt/chNN/narration.ru.json site/opt/chNN/audio/ru   # озвучка (Edge TTS), нужен ffmpeg
uv run --with playwright tools/shots.py NN     # скриншоты шагов главы
uv run --with playwright tools/errs.py opt NN  # ошибки по всем шагам главы
uv run --with playwright tools/build_bank.py   # банк вопросов экзамена
python tools/sync_toc.py                       # оглавление из глав
uv run --with playwright tools/e2e_player.py 03  # автотест плеера: 2×, скорость, перемотка
```

Устройство книги: `books/opt/style.json` (настройки), `content/opt/chNN/narration.ru.json` (озвучка), `site/opt/` (готовый учебник: `lib/engine.js` и соседние файлы — движок Papermorph, не править; `opt.js` — графики, формулы, листинги; `methods.js` — методы, сверенные с программами; `board.js` — элементы доски; `gens.js` — генераторы задач). Правила написания глав — `AUTHORING.md`.
